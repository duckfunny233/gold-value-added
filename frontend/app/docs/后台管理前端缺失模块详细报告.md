## 二、缺失模块详细清单

### 🔴 严重缺失模块

#### 1. 实名认证审核模块（身份核实板块）

**需求来源**：需要登录身份信息核实板块，需要能够看到注册填写的信息并且进行审核操作。

**缺失内容**：
- 用户实名信息列表（真实姓名、身份证号、身份证正反面照片、资质证明）
- 实名认证状态筛选（待审核 / 已通过 / 已拒绝）
- 实名审核操作（通过 / 拒绝 + 备注）
- 用户注册信息详情页（手机号、注册渠道、注册时间、设备信息）

**后端已有支持**：
- `backend/src/modules/user/user.controller.ts` L79：`manualCheckUser` 接口已存在

**前端缺失**：完全没有对应的页面和路由。

---

#### 2. 充值订单详情与对账模块

**需求来源**：充值的要显示多少钱。

**现有问题**：`FundsView.vue` L211-241 充值列表仅显示基础信息。

**缺失内容**：
- 充值订单详情弹窗（显示充值金额、渠道、状态、用户手机号脱敏后四位）
- 对账操作按钮（标记为已对账 / 异常）
- 充值渠道收款码管理（等待提供银行卡、支付宝、微信收款码上传功能）

---

#### 3. 提现审核操作模块

**需求来源**：提现的要显示多少钱，显示手机号四位才行。

**现有问题**：`FundsView.vue` L244-280 提现列表仅展示，无审核操作。

**缺失内容**：
- 提现详情抽屉（显示提现金额、用户手机号后四位、收款信息）
- 审核操作按钮：通过 / 拒绝 / 标记转账完成
- 提现静音 / 提醒控制

**后端已有支持**：
- `backend/src/modules/fund/fund.controller.ts` L120-146：`approveWithdrawal`、`rejectWithdrawal`、`confirmWithdrawalCompleted` 接口已存在

**前端缺失**：列表有数据但无任何操作按钮。

---

## 五、总结

后台管理前端**框架已搭建完成**，但存在以下关键问题：

1. **核心业务流程未闭环**：实名认证审核、提现审核等核心操作前端完全缺失或仅展示无操作。
2. **接口对接不完整**：停盘 / 恢复、风控规则更新、排行榜治理等操作仅保留弹窗，未实际调用后端接口。
3. **信息展示不完整**：用户手机号脱敏显示、实名信息展示等需求未实现。
4. **系统配置模块缺失**：交易时段、数据归档等后续优化模块尚未开始。

---

**下一步建议**：
- 优先完成 P0 级别模块（实名认证审核、提现审核）。
- 补充 P1 级别功能（充值对账、用户详情页完善）。
- 逐步对接 P2 级别接口调用（停盘、风控规则、排行榜治理）。
- 规划 P3 级别模块（系统配置、数据归档）。
