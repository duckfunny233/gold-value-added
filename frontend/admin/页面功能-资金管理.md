# 页面功能-资金管理

## 页面目标与角色权限
- 页面目标：处理充值对账、提现审核、补款转账、资产调整和支付渠道对账。
- 可访问角色：财务、平台管理员、风控只读、审计只读。

## 页面路由建议与布局分区
- 路由：`/admin/funds`
- 布局分区：

  - 中部充值/提现双 Tab

## 状态机与业务校验（含禁用态）
- 状态机：
  - 充值：`auto_credited -> reconciling -> reconciled`
  - 提现：`pending_review(frozen) -> transfer_processing -> completed | rejected`
- 业务校验：
  - 充值按 24 小时自动到账处理，仅供对账查看
  - 充值到账后直接写入暂定资产和总资产
  - 提现仅交易时间可发起
  - 用户提交提现后，系统立即冻结提现金额并扣减暂定资产，同步扣减总资产
  - 提现扣减只允许发生在提交时，确认完成时不得二次扣款
  - 提现审核时必须清晰展示微信收款码、支付宝收款码、银行卡号
  - 提现订单必须按提交时间自动排队并顺序展示
  - 提现新单进入队列后立即触发后台语音播报并持续响铃
  - 进入订单详情或手动静音后，当前订单语音提醒停止
  - 人工线下转账完成后点击 `ConfirmWithdrawCompleted`，订单改为 `completed`
  - 提现拒绝时必须解冻并回补暂定资产和总资产
  - 后台手工转账/补款后资产必须实时到账/减账
  - 支付渠道对账必须覆盖微信、支付宝、银行卡
- 禁用态：
  - 已完成提现单禁用 `ConfirmWithdrawCompleted`
  - 非 `pending_review` 状态禁用 `MuteWithdrawAlert`
  - 充值单禁用人工审核按钮

## 异常提示与空态规则
- 异常提示：
  - `提现冻结失败`
  - `提现确认完成失败`
  - `提现语音提醒下发失败`
  - `渠道对账失败`
  - `资产调整失败`
- 空态：
  - `暂无资金订单`
