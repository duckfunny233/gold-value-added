# 页面功能-用户管理

## 页面目标与角色权限
- 页面目标：完成用户全生命周期管理与跨模块关联查询。
- 可访问角色：平台管理员、财务、风控、客服、审计只读。

## 页面路由建议与布局分区
- 路由：`/admin/users`
- 布局分区：
  - 顶部筛选区
  - 中部用户列表
  - 右侧用户详情抽屉
  - 底部关联记录标签页

## 查询条件、列表字段、详情字段、操作按钮
- 查询条件：
  - `userId`
  - `uid`
  - `sequenceNo`
  - `realNameStatus`
  - `rechargeStatus`
  - `withdrawStatus`
- 列表字段：
  - `userId`
  - `uid`
  - `sequenceNo`
  - `nickname`
  - `realNameStatus`
  - `rechargeStatus`
  - `withdrawStatus`
  - `cashAsset`
  - `goldHoldingGrams`
  - `totalAsset`
- 详情字段：
  - `appreciationIncome`
  - `payoutProfileSummary`
  - `riskStatus`
  - `lastTradeAt`
  - `latestTraceId`
- 操作按钮：
  - `ViewDetail`
  - `FreezeUser`
  - `UnfreezeUser`
  - `ManualCheck`
  - `ExportUsers`
  - `BatchVerifyPayoutProfiles`

## 状态机与业务校验（含禁用态）
- 状态机：`active -> frozen -> active`
- 业务校验：
  - 用户列表必须可按 UID 和注册序号检索
  - 用户详情必须可关联充值、提现、交易、资金流水和审计记录
  - 批量校验收款信息必须记录操作日志
- 禁用态：
  - 冻结用户禁用重复冻结
  - 正常用户禁用解冻按钮

## 异常提示与空态规则
- 异常提示：
  - `用户列表加载失败`
  - `用户冻结失败`
  - `批量校验收款信息失败`
- 空态：
  - `暂无匹配用户`

- 跳转到：
