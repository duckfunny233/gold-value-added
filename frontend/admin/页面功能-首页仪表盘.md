# 页面功能-首页仪表盘

## 页面目标与角色权限
- 页面目标：承接全局总览、待办提醒、系统监控、事件流、规则提醒和公告轮播管理。
- 可访问角色：平台管理员、财务、风控、审计、客服只读。

## 页面路由建议与布局分区
- 路由：`/admin/dashboard`
- 布局分区：
  - 顶部核心指标卡片
  - 左侧待处理单据
  - 右侧系统监控与公告管理
  - 底部实时事件流与规则提醒

## 查询条件、列表字段、详情字段、操作按钮
- 查询条件：
  - `date`
  - `module`
  - `severity`
- 指标字段：
  - `pendingAuditCount`
  - `frozenUserCount`
  - `goldReferencePrice`
  - `tradingStatus`
- 监控字段：
  - `syncDelay`
  - `leaderboardRebuildStatus`
  - `paymentReconcileStatus`
  - `withdrawAlertRingingCount`
- 公告字段：
  - `noticeId`
  - `title`
  - `status`
  - `publishAt`
  - `pollingEnabled`
- 操作按钮：
  - `PublishNotice`
  - `EditNotice`
  - `DeleteNotice`
  - `PauseTrading`
  - `ResumeTrading`
  - `RefreshDashboard`

## 状态机与业务校验（含禁用态）
- 状态机：`running -> paused -> running`
- 业务校验：
  - 黄金参考价按 AU9999 实时刷新
  - 公告发布后前端首页必须轮巡展示
  - 系统监控必须覆盖同步延迟、排行榜重排、支付对账
  - 提现新单触发语音持续提醒时，仪表盘需实时显示提醒中的订单数量
- 禁用态：
  - 停盘时禁用 `PauseTrading`
  - 运行中禁用 `ResumeTrading`

## 异常提示与空态规则
- 异常提示：
  - `仪表盘数据加载失败`
  - `系统监控数据异常`
  - `公告发布失败`
- 空态：
  - `当前无待处理单据`
  - `当前无实时事件`

- 跳转到：
  - `资金管理`
  - `交易管理`
  - `权限与风控`
  - `报表中心`
