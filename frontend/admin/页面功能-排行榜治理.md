# 页面功能-排行榜治理

## 页面目标与角色权限
- 页面目标：完成排行榜重排、规则校验、同步监控和异常处理。
- 可访问角色：平台管理员、运营、审计、客服只读。

## 页面路由建议与布局分区
- 路由：`/admin/leaderboard`
- 布局分区：
  - 顶部重排与规则配置区
  - 中部排行榜列表
  - 右侧同步监控与异常处理面板

## 查询条件、列表字段、详情字段、操作按钮
- 查询条件：
  - `uid`
  - `sortRule`
  - `syncStatus`
  - `timeRange`
- 列表字段：
  - `rank`
  - `uid`
  - `nickname`
  - `goldHoldingGrams`
  - `totalAsset`
  - `syncStatus`
  - `updatedAt`
- 详情字段：
  - `sortRule`
  - `rebuildVersion`
  - `lastSyncAt`
  - `exceptionReason`
- 操作按钮：
  - `RebuildLeaderboard`
  - `ValidateRule`
  - `UpdateSortRule`
  - `HandleException`
  - `Export`

## 状态机与业务校验（含禁用态）
- 状态机：`idle -> rebuilding -> synced|exception`
- 业务校验：
  - 排行榜支持按黄金克数或总资产排序配置
  - 每次重排都要保留版本和日志
  - 同步异常必须能人工处理并复核
- 禁用态：
  - `rebuilding` 状态禁用再次重排

## 异常提示与空态规则
- 异常提示：
  - `排行榜重排失败`
  - `同步异常处理失败`
- 空态：
  - `暂无排行榜数据`
