# 金链·GYC 后台前端说明

## 1. 后台目标

`frontend/admin` 对应后台管理端，当前版本严格按八大模块开发，核心目标是“职责清晰、数据归属清晰、操作可审计”。

## 2. 后台模块

1. 首页仪表盘：总览、待办、监控、事件流、公告、规则提醒
2. 用户管理：全生命周期管理和关联数据查询
3. 交易管理：买卖撮合、交易控制、同步重试、交易时间控制
4. 资金管理：充值对账、提现审核、补款转账、资产调整、渠道对账
5. 排行榜治理：重排、规则配置、同步监控、异常处理
6. 权限与风控：权限、角色、冻结、停盘、提现拦截、风险预警
7. 审计追溯：按 `traceId` 全链路追踪、SHA-256 哈希校验、半公开金链同步校验
8. 报表中心：运营报表、导出、可视化

## 3. 后台 UI 约束

1. 每个模块必须明确写出数据来源和操作边界。
2. 高风险动作必须保留二次确认和操作日志。
3. 仪表盘必须包含公告发布、系统监控、实时事件流和前端轮巡展示说明。
4. 资金管理不得再出现“充值人工审核”入口，且要明确 24 小时自动到账。
5. 提现提交后必须立即冻结金额并扣减暂定资产/总资产，确认完成不得二次扣款。
6. 提现新单必须触发后台语音持续提醒，进入订单详情或手动静音后停止。
7. 交易管理必须有买卖、停盘、上金所交易时段自动同步监控、提现交易时间限制说明和同步重试能力，不得提供人工固定时段配置入口。
8. 审计追溯必须明确 64 位 SHA-256 哈希和半公开金链同步。
