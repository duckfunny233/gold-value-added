# 页面功能-交易管理

## 页面目标与角色权限
- 页面目标：完成买卖交易全流程管控、撮合监控、停盘控制和上金所交易时段同步监控。
- 可访问角色：平台管理员、风控、财务只读、审计只读。

## 页面路由建议与布局分区
- 路由：`/admin/trades`
- 布局分区：
  - 顶部交易指标区
  - 中部交易列表
  - 右侧撮合与同步控制面板
  - 底部上金所交易时段同步状态区

## 状态机与业务校验（含禁用态）
- 状态机：`running -> paused -> running`
- 业务校验：
  - 交易列表必须覆盖买单和卖单
  - 交易撮合逻辑必须写入代码
  - 价格优先：高买先成交
  - 时间优先：同价按提交时间先后成交
  - 交易时段必须自动同步上金所官方时间，禁止人工配置固定时段
  - 上金所开盘时段（Asia/Shanghai）：周一至周五 `09:00-11:30`、`13:30-15:30`、`20:00-次日02:30`
  - 周六、周日、法定节假日自动休市
  - 非交易时间禁止买卖
- 禁用态：
  - 停盘时禁用 `PauseTrading`
  - 非停盘时禁用 `ResumeTrading`

## 异常提示与空态规则
- 异常提示：
  - `交易列表加载失败`
  - `同步重试失败`
  - `上金所交易时段同步异常`
- 空态：
  - `暂无交易记录`
