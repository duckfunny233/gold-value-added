# 业务规则与账本模型

## 1. 用户与追踪主键

1. 用户注册成功后生成唯一且固定不变的 `uid`。
2. 资金、交易、支付、审计、风控统一以 `uid` 为主业务索引。
3. 所有关键动作必须生成 `traceId`，并落库 SHA-256（64 位）哈希存证。

## 2. 统一手续费规则（强约束）

1. 买入手续费：`0.1%`（`feeRate = 0.001`）。
2. 卖出手续费：`0.1%`（`feeRate = 0.001`）。
3. 提现手续费：`0.1%`（`feeRate = 0.001`）。
4. 点对点支付手续费由收款方承担：`1‰`（`receiverFeeRate = 0.001`）。
5. 点对点支付手续费阈值：`amount < 100` 不收，`amount >= 100` 按 `1‰` 计算。
6. 点对点支付手续费取整口径：按财务规则取整（建议向下保留 2 位小数，后续若有财务中心统一口径，以财务中心为准）。

## 3. 充值规则

1. 充值创建后进入 24 小时自动到账流程，无人工审核。
2. 充值成功后同事务更新账本：`tentativeAsset`、`cashAsset`、`principalBalance`、`withdrawablePrincipal`、`totalAsset`。
3. 充值动作必须写入充值流水、渠道流水、审计日志、哈希与金链同步记录。

## 4. 提现规则

1. 提现仅允许在交易时段发起。
2. 提交提现时系统必须立即冻结提现金额，并同步扣减 `tentativeAsset` 与 `totalAsset`。
3. 提现实发金额 = `amount - feeAmount`，其中 `feeAmount = amount * 0.001`。
4. 后台确认提现仅允许完结订单，不允许二次扣款。
5. 提现拒绝必须原路解冻回补：`tentativeAsset + frozenAmount`、`totalAsset + frozenAmount`。

## 5. 点对点支付扣款顺序（强约束）

1. 用户发起点对点支付/消费时，必须先扣 `appreciationIncome`（增值）。
2. 仅当增值不足时，才允许扣 `principalBalance`（本金）。
3. 禁止先扣本金再扣增值。
4. 一旦支付动用了本金，必须同步减少 `withdrawablePrincipal`。
5. 扣款结果需要返回拆分字段：`appreciationUsed`、`principalUsed`。

## 6. 本金可提现额度规则

1. `withdrawablePrincipal` 表示用户当前仍可提现的本金额度。
2. 充值增加本金时，`principalBalance` 与 `withdrawablePrincipal` 同步增加。
3. 点对点支付/消费动用本金时，`principalBalance` 与 `withdrawablePrincipal` 同步减少。
4. 增值部分被消费不会减少 `withdrawablePrincipal`。

### 6.1 示例（必须实现）

1. 充值 `1000`，则 `withdrawablePrincipal = 1000`。
2. 资产上涨到 `1500`，则 `appreciationIncome = 500`。
3. 发起支付 `800`，按强制顺序扣款：先扣增值 `500`，再扣本金 `300`。
4. 支付后 `withdrawablePrincipal = 700`，该用户后续最多只能提现 `700` 本金。

## 7. 交易与撮合规则

1. 交易范围仅买入和卖出。
2. 撮合规则固定写入代码：价格优先、时间优先。
3. 非交易时段、停盘状态、冻结用户均禁止提交买卖。
4. 成交后必须记录：主单、资产变化、手续费、`traceId`、哈希、金链同步状态。

## 8. 资产模型主口径

1. `tentativeAsset`
2. `cashAsset`
3. `appreciationIncome`
4. `principalBalance`
5. `withdrawablePrincipal`
6. `withdrawFrozenAmount`
7. `goldHoldingGrams`
8. `totalAsset`

## 9. 行情与时段同步

1. 行情标的为上金所 AU9999。
2. 交易时段自动同步上金所官方时间（Asia/Shanghai）：`09:00-11:30`、`13:30-15:30`、`20:00-次日02:30`。
3. 周六、周日、法定节假日自动休市。

## 10. 验收清单

1. 充值 24 小时自动到账并更新资产与审计留痕。
2. 提现仅交易时间可发起，提交即冻结并扣减，确认不二扣，拒绝可回补。
3. 买入、卖出、提现均按 `0.1%` 计算手续费并返回费用字段。
4. 点对点支付按“先增值后本金”扣款，返回 `appreciationUsed` 与 `principalUsed`。
5. 点对点收款手续费按 `1‰` 执行，`amount < 100` 不扣。
6. 动用本金后 `withdrawablePrincipal` 必须联动下降。
7. 前后台资金、交易、提现队列与提醒状态保持秒级同步。
8. 所有关键动作可通过 `traceId + SHA-256` 完整追溯。
