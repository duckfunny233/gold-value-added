# 接口-数据库收口联调 V2

本文件记录后台管理端 `frontend/admin` 与 `backend` 的联调收口结果，目标是把现有按钮统一接到真实 API 与真实数据库，不再回退本地 mock。

## 1. 联调范围

- 前端
  - `frontend/admin/src/services/admin.js`
  - `frontend/admin/src/views/*`
- 后端
  - `backend/src/modules/dashboard/*`
  - `backend/src/modules/fund/*`
  - `backend/src/modules/trade/*`
  - `backend/src/modules/risk/*`
  - `backend/src/modules/user/*`
  - `backend/src/modules/leaderboard/*`
  - `backend/src/modules/audit/*`
  - `backend/src/modules/report/*`

## 2. 前端策略

- 已移除 `frontend/admin/src/services/admin.js` 中的本地 mock fallback。
- 后台页面全部改为真实 API 请求失败即提示错误，不再读取 `frontend/shared/mocks/admin.js` 兜底。
- 页面结构保持不变，按钮通过以下方式接入真实动作：
  - 行点击选中当前记录
  - `window.prompt / window.confirm` 收集最小输入
  - 现有错误区与说明区显示操作结果

## 4. 数据与状态流转

### 4.1 资金规则保持不变

- 充值创建后自动到账：
  - `tentativeAsset + amount`
  - `cashAsset + amount`
  - `totalAsset + amount`
- 提现提交即冻结：
  - `tentativeAsset - amount`
  - `totalAsset - amount`
  - `withdrawFrozenAmount + amount`
- 提现确认完成：
  - 仅 `withdrawFrozenAmount - amount`
  - 不允许二次扣减 `tentativeAsset / totalAsset`
- 提现拒绝：
  - `tentativeAsset + amount`
  - `totalAsset + amount`
  - `withdrawFrozenAmount - amount`

### 4.2 交易规则保持不变

- 交易只允许在交易时段内提交
- 全站停盘时买卖请求被拒绝
- 冻结用户交易被拒绝
- 撮合规则固定：
  - 价格优先
  - 时间优先

### 4.3 审计与哈希

- 所有新增管理动作继续使用 64 位 `SHA-256`
- 所有后台动作统一可追溯 `traceId`
- 所有关键写接口继续同步写入：
  - `AdminOperationLog`
  - `AuditLog`
  - `HashRecord`
