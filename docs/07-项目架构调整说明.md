## 3. 工程职责

### 3.1 `frontend/app`

负责用户端能力：

1. 注册登录和 UID 展示
2. 充值提交与到账状态查看
3. 提现申请
4. 买单、卖单提交
5. AU9999 行情与 K 线展示
6. 首页公告轮播展示

### 3.2 `frontend/admin`

负责八大后台模块页面：

1. 首页仪表盘
2. 用户管理
3. 交易管理
4. 资金管理
5. 排行榜治理
6. 权限与风控
7. 审计追溯
8. 报表中心

### 3.3 `backend`

负责后端服务拆分与数据域实现：

1. 用户与认证服务
2. 资金服务
3. 交易与撮合服务
4. 行情服务
5. 公告与仪表盘服务
6. 排行榜治理服务
7. 风控服务
8. 审计服务
9. 报表服务

### 3.4 `docs`

负责统一业务主规则、模块职责、接口规范和迁移说明。

## 4. 当前边界

1. 仪表盘负责全局总览、公告、监控和事件流，不负责具体业务审核。
2. 资金管理负责充值对账、提现审核、补款转账和资产调整。
3. 交易管理负责买卖撮合、同步控制、停盘、交易时间控制。
4. 审计追溯和报表中心消费全模块数据，但不反向主导业务规则。
