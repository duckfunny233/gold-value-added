## 通用约定

- 除登录外，请求头需携带：`Authorization: Bearer <admin_token>`
- 统一响应外壳：`{ code, message, traceId?, data }`（`code === 200` 为业务成功）
- 时间范围 Query 枚举：`today` | `7d` | `30d`
- **与 C 端联动**：不以路径相同为准，而以 `uid`、订单号、`traceId` 与 `接口文档/客户端` 对齐；详见 [00-共用汇总·第二节](./00-后台管理一期共用接口汇总.md#二与客户端数据联动对照端管共用字段)
