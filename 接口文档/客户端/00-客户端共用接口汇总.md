# 客户端共用接口汇总

## 统计口径
- 统计范围：`接口文档/客户端/01-22` 全部页面接口文档。
- 共用接口定义：同一个“请求方法 + 接口路径”被 2 个及以上页面使用。
- 排序规则：按“使用接口页面数量”从多到少；数量相同按业务优先级排序。

## 共用接口总表（按使用次数降序）
| 排名 | 接口 | 接口功能描述 | 使用该接口页面 | 使用次数 |
| --- | --- | --- | --- | --- |
| 1 | `GET /api/user/profile` | 获取用户资料、实名状态、资产与持仓，用于资产展示与交易前校验 | `13-交易页-Trade`、`14-个人中心-Profile` | 2 |
| 2 | `GET /api/chat/list` | 获取会话列表、最后一条消息、会话类型；用于聊天列表展示与会话标题回填 | `07-聊天列表-Chat`、`08-聊天详情-ChatDetail` | 2 |

## 共用接口字段属性表

### 1) GET /api/user/profile
**接口功能描述**  
获取当前登录用户基础信息、资产总览和持仓数据，支持个人中心展示与交易页资金校验。

**使用该接口页面**  
`13-交易页-Trade`、`14-个人中心-Profile`

**接口相关字段属性表**
| 字段 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| `Authorization` | Header | string | 是 | `Bearer <token>` |
| `code` | Response | number | 是 | 业务状态码，成功通常为 `200` |
| `message` | Response | string | 是 | 业务提示信息 |
| `data.uid` | Response | string | 是 | 用户唯一编号 |
| `data.nickname` | Response | string | 是 | 用户昵称 |
| `data.realNameVerified` | Response | boolean | 是 | 实名状态 |
| `data.assets[]` | Response | array | 是 | 资产汇总列表（总资产、余额等） |
| `data.goldPositions[]` | Response | array | 否 | 黄金持仓列表 |
| `data.silverPositions[]` | Response | array | 否 | 白银持仓列表 |
| `data.withdrawablePrincipal` | Response | number/string | 建议 | 可提现本金（新规则建议固定返回） |
| `data.principalBalance` | Response | number/string | 建议 | 本金余额（新规则建议固定返回） |
| `data.appreciationIncome` | Response | number/string | 建议 | 增值余额（新规则建议固定返回） |

### 2) GET /api/chat/list
**接口功能描述**  
获取用户会话清单，支持聊天首页会话渲染，以及聊天详情页根据 `chatId` 回填标题和会话类型。

**使用该接口页面**  
`07-聊天列表-Chat`、`08-聊天详情-ChatDetail`

**接口相关字段属性表**
| 字段 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| `Authorization` | Header | string | 是 | `Bearer <token>` |
| `code` | Response | number | 是 | 业务状态码，成功通常为 `200` |
| `message` | Response | string | 否 | 业务提示信息 |
| `data[]` | Response | array | 是 | 会话列表 |
| `data[].id` | Response | string/number | 是 | 会话 ID |
| `data[].name` | Response | string | 是 | 会话名称（用户/群） |
| `data[].type` | Response | string | 是 | 会话类型，如 `user`、`group` |
| `data[].lastMsg` | Response | string | 否 | 最后一条消息摘要 |
| `data[].time` | Response | string | 否 | 最近消息时间展示值 |

## 端管数据联动（与后台管理一期对齐）

客户端与管理端 **HTTP 路径不同**，但共用同一 PostgreSQL 业务库。联调、排障时以下字段必须一致：

| 联动主键 | 客户端典型来源 | 管理端一期查询 | 说明 |
| --- | --- | --- | --- |
| `uid` | `POST /api/auth/login` → `data.user.uid`；`GET /api/user/profile` → `data.uid` | `GET /api/admin/users?uid=` | 同一 `User.uid` |
| `orderId` | `POST /api/wallet/recharge`、`/withdraw` | `GET /api/admin/funds` → `rechargeRows` / `withdrawRows` | 充值/提现单主键 |
| `tradeNo` | `GET /api/app/trades` | `GET /api/admin/trades` | 均为 `TradeOrder.id` |
| `traceId` | 充提/交易写操作响应 | `ledgerRows`、`GET /api/admin/audit/trace/:traceId` | 全链路追踪 |

完整对照表（含资产口径、状态枚举映射、已知差异 D1–D6）见：  
**`接口文档/后台管理一期/00-后台管理一期共用接口汇总.md` 第二节**。

> 管理员 `admin_token` 与 C 端 `token` **不可混用**。

## 备注
- 当前客户端页面接口大多为单页专用接口，因此“跨页面复用”的精确接口数量较少。
- 如后续将设置模块全部切换到后端真实接口，可在本文件追加新的复用项并重新排序。
