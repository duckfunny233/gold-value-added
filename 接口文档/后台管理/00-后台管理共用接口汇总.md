# 后台管理共用接口汇总

## 统计口径
- 统计范围：`接口文档/后台管理/01-11` 全部页面接口文档。
- 共用接口定义：同一个“请求方法 + 接口路径”被 2 个及以上页面使用。
- 排序规则：按“使用接口页面数量”从多到少；数量相同按业务优先级排序。

## 共用接口总表（按使用次数降序）

| 排名 | 接口 | 接口功能描述 | 使用该接口页面 | 使用次数 |
| --- | --- | --- | --- | --- |
| 1 | `POST /api/admin/reports/generate` | 生成报表任务，支持运营/财务/风控/审计等类型 | `02-用户管理`、`03-交易管理`、`04-资金管理`、`05-排行榜治理`、`07-审计追溯` | 5 |
| 2 | `POST /api/admin/auth/login` | 管理员登录，返回 token 与角色权限 | `01-登录页`、所有需要鉴权的页面 | 10+ |
| 3 | `GET /api/admin/auth/profile` | 获取当前管理员资料与权限 | 所有需要鉴权的页面 | 10+ |

## 共用接口字段属性表

### 1) POST /api/admin/reports/generate
**接口功能描述**  
生成后台报表任务，支持运营数据、财务/交易数据、风控规则、审计追溯等类型，生成后可到报表中心下载。

**使用该接口页面**  
`02-用户管理`、`03-交易管理`、`04-资金管理`、`05-排行榜治理`、`07-审计追溯`

**接口相关字段属性表**
| 字段 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| `Authorization` | Header | string | 是 | `Bearer <token>` |
| `reportType` | Body | string | 是 | 报表类型：`operate` / `finance` / `risk` / `audit` |
| `timeRange` | Body | string | 否 | 时间范围：`today` / `7d` / `30d` |
| `uid` | Body | string | 否 | 目标用户 UID |
| `channel` | Body | string | 否 | 支付渠道 |
| `format` | Body | string | 否 | 导出格式：`csv` / `excel`，默认 `csv` |
| `name` | Body | string | 否 | 报表名称 |
| `code` | Response | number | 是 | 业务状态码，成功通常为 `200` |
| `message` | Response | string | 是 | 业务提示信息 |
| `data.jobId` | Response | string | 是 | 报表任务 ID |

### 2) POST /api/admin/auth/login
**接口功能描述**  
管理员账号密码登录，校验通过后返回 JWT token 及管理员基本信息（含角色与权限码）。

**使用该接口页面**  
`01-登录页`、所有需要鉴权的后台页面

**接口相关字段属性表**
| 字段 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| `username` | Body | string | 是 | 管理员登录账号 |
| `password` | Body | string | 是 | 管理员登录密钥 |
| `code` | Response | number | 是 | 业务状态码，成功通常为 `200` |
| `message` | Response | string | 是 | 业务提示信息 |
| `data.token` | Response | string | 是 | JWT 登录令牌 |
| `data.adminUser.username` | Response | string | 是 | 管理员账号 |
| `data.adminUser.displayName` | Response | string | 是 | 显示名称 |
| `data.adminUser.roleCodes` | Response | array | 是 | 角色编码列表 |
| `data.adminUser.permissionCodes` | Response | array | 是 | 权限编码列表 |

### 3) GET /api/admin/auth/profile
**接口功能描述**  
获取当前登录管理员资料，包括账号、显示名称、角色、权限及最近登录时间。

**使用该接口页面**  
所有需要鉴权的后台页面（通常用于顶部导航栏展示与权限控制）

**接口相关字段属性表**
| 字段 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| `Authorization` | Header | string | 是 | `Bearer <token>` |
| `code` | Response | number | 是 | 业务状态码，成功通常为 `200` |
| `message` | Response | string | 是 | 业务提示信息 |
| `data.username` | Response | string | 是 | 管理员账号 |
| `data.displayName` | Response | string | 是 | 显示名称 |
| `data.status` | Response | string | 是 | 账号状态：`ACTIVE` / `FROZEN` |
| `data.lastLoginAt` | Response | string | 否 | 最近登录时间 |
| `data.roles` | Response | array | 是 | 角色列表（含 code、name） |
| `data.permissions` | Response | array | 是 | 权限编码列表 |

## 备注
- 所有后台管理接口（除登录外）均需在 `Authorization` Header 中携带 `Bearer <token>`。
- 部分敏感操作（如资金手工转账、风控规则更新）还需具备对应的权限码（`ADMIN_PERMISSION_CODES`）。
