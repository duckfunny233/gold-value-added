# 金影子测试分析

## 系统架构分析

### 后端系统
- **框架**：Nest.js
- **数据库**：Prisma ORM
- **核心模块**：
  - admin-auth: 后台认证
  - audit: 审计
  - auth: 认证
  - chat: 聊天
  - dashboard: 仪表盘
  - fund: 资金
  - leaderboard: 排行榜
  - market: 市场
  - payment: 支付
  - report: 报表
  - risk: 风控
  - trade: 交易
  - user: 用户

### 前端后台管理系统
- **框架**：Vue.js
- **核心页面**：
  - AuditView: 审计视图
  - DashboardView: 仪表盘视图
  - FundsView: 资金视图
  - LeaderboardView: 排行榜视图
  - LoginView: 登录视图
  - ReportsView: 报表视图
  - RiskView: 风控视图
  - TradesView: 交易视图
  - UsersView: 用户视图

### 前端客户端系统
- **框架**：Vue.js
- **核心页面**：
  - 认证相关：Login, Register, ForgotPassword
  - 聊天相关：Chat, ChatDetail, AddFriend, CreateGroup, Scan
  - 设置相关：SettingsHome, AccountSettings, SecuritySettings, GeneralSettings, AboutSettings, HelpServiceSettings, CancelAccountSettings
  - 资讯相关：NewsList, NewsDetail, ActivityDetail(/activity/:id)
  - 其他：Home, Market, Profile, Trade, GoldChain
  - 关键弹窗组件：MyQrModal, TransferModal, RechargeModal, WithdrawModal, PaymentMethodModal

## 测试策略建议

1. **单元测试**：针对各个模块的核心功能进行测试，确保每个模块的功能正常。

2. **集成测试**：测试模块之间的交互，确保系统各部分协同工作。

3. **端到端测试**：模拟用户操作流程，测试整个系统的功能完整性。

4. **性能测试**：测试系统在高负载下的表现，确保系统稳定性。

5. **安全测试**：测试系统的安全防护措施，确保系统安全。

6. **兼容性测试**：测试系统在不同设备、浏览器上的表现，确保系统兼容性。

7. **回归测试**：在系统更新后，测试原有功能是否正常，确保系统稳定性。

考虑当前由一人负责开发与测试，建议采用“按模块闭环”的执行方式：每个模块一次性完成单元、集成、契约三层测试，避免后期集中返工。

1. **确定P0模块优先级**
   - 先做：`auth`、`fund`、`trade`、`risk`
   - 原则：先覆盖资金与交易相关高风险链路

2. **先搭测试底座（一次完成）**
   - 准备独立测试数据库（不要使用生产库）
   - 准备初始化测试数据与清理脚本
   - 统一测试账号、管理员账号、基础鉴权信息

3. **按模块做“闭环测试”**
   - 顺序：`auth -> fund -> trade -> risk`
   - 每个模块固定流程：
     - 服务层单元测试（Jest）
     - 数据库集成测试（真实PostgreSQL测试库）
     - 控制器契约测试（supertest/接口断言）

4. **补Apifox回归集合（边做边补）**
   - 按模块建立集合：`auth`、`fund`、`trade`、`risk`
   - 每个关键接口至少覆盖：
     - 正常用例
     - 参数错误用例
     - 权限错误用例
     - 重复提交/幂等用例

5. **最后做业务闭环E2E**
   - 主流程：注册 -> 登录 -> 充值 -> 交易 -> 提现 -> 后台审核 -> 审计追踪
   - 反向流程：余额不足、停盘下单、幂等冲突

6. **形成发版前固定回归动作**
   - 固定一套“上线前必跑”的命令与用例清单
   - 达到标准后再发布：P0用例通过、资金链路无阻塞缺陷、幂等并发专项通过

## 总结

本测试分析文档提供了金影子系统的完整测试用例规划，包括单独页面内的测试、同一系统内页面之间的互相测试、两个系统之间的联调测试三个大板块。通过这些测试，可以确保系统的功能完整性、稳定性和安全性，为系统的上线和后续维护提供保障。
