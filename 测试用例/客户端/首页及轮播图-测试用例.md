# 客户端首页及轮播图测试用例

## 覆盖范围
- 页面：`/home`、`/news/:id`
- 对应文档：
- `接口文档/客户端/04-首页-Home.md`
- `接口文档/客户端/06-新闻详情-NewsDetail.md`
- 接口：
- `GET /api/notice`
- `GET /api/news?page={page}&limit={limit}`
- `GET /api/news/{id}`
- `GET /api/public/leaderboard`

## 通用前置条件
- 后端服务已启动，接口可访问
- 数据库存在可展示的新闻与排行榜数据
- 前端已登录并进入首页

## 一、等价类测试

### TC-EQ-HOME-001
- 编号：`TC-EQ-HOME-001`
- 测试点：公告接口有效等价类（返回正常公告）
- 前置条件：`/api/notice` 有可用文案
- 步骤：
1. 打开首页
2. 观察顶部公告滚动条
- 数据：`GET /api/notice`
- 预期结果：
1. 返回 `200`
2. 页面展示 `data.text`
3. 公告滚动展示，不出现“网络连接失败”

### TC-EQ-HOME-002
- 编号：`TC-EQ-HOME-002`
- 测试点：新闻轮播有效等价类（首页取前 N 条）
- 前置条件：新闻接口有数据
- 步骤：
1. 打开首页
2. 检查轮播区域
3. 点击第一条轮播新闻
- 数据：`GET /api/news?page=1&limit=5`
- 预期结果：
1. 返回 `200`
2. 响应包含 `data.items[]` 和 `data.total`
3. 轮播图展示新闻标题和封面
4. 点击后跳转 `/news/{id}`

### TC-EQ-HOME-003
- 编号：`TC-EQ-HOME-003`
- 测试点：排行榜有效等价类（返回 Top10）
- 前置条件：`/api/public/leaderboard` 有数据
- 步骤：
1. 打开首页
2. 查看金字塔排行展示
- 数据：`GET /api/public/leaderboard`
- 预期结果：
1. 返回 `200`
2. 页面渲染排行数据
3. 排序满足 `goldGrams desc -> totalAsset desc -> sequenceNo asc`

### TC-EQ-NEWS-001
- 编号：`TC-EQ-NEWS-001`
- 测试点：新闻详情有效等价类
- 前置条件：存在有效新闻 `id`
- 步骤：
1. 从首页轮播点击新闻进入详情
2. 查看标题、正文、封面、时间
- 数据：`GET /api/news/{id}`
- 预期结果：
1. 返回 `200`
2. 页面展示 `data.id/title/content`
3. 时间字段可由 `createdAt` 正常回显
4. 封面字段可由 `cover` 正常回显

## 二、边界值测试

### TC-BV-NEWS-001
- 编号：`TC-BV-NEWS-001`
- 测试点：新闻分页下边界（`page=1, limit=1`）
- 前置条件：新闻总量 >= 1
- 步骤：请求新闻列表并进入首页渲染
- 数据：`GET /api/news?page=1&limit=1`
- 预期结果：
1. 返回 `200`
2. `items.length=1`
3. 首页轮播仅展示 1 条，不报错

### TC-BV-NEWS-002
- 编号：`TC-BV-NEWS-002`
- 测试点：新闻分页上边界（`limit=50`）
- 前置条件：新闻接口支持 `limit` 参数
- 步骤：调用新闻列表接口
- 数据：`GET /api/news?page=1&limit=50`
- 预期结果：
1. 返回 `200`
2. 数据结构仍为 `items/total/page/limit/totalPages`
3. 前端可正常截取首页展示数量，不出现卡死

### TC-BV-RANK-001
- 编号：`TC-BV-RANK-001`
- 测试点：排行榜临界数据（第10名与第11名）
- 前置条件：存在至少 11 条候选数据
- 步骤：请求排行榜并核对首页显示
- 数据：`GET /api/public/leaderboard`
- 预期结果：
1. 页面最多展示 10 条
2. 第10名符合排序规则，不被第11名误替换

## 三、场景法测试

### TC-SC-HOME-001
- 编号：`TC-SC-HOME-001`
- 测试点：首页完整业务场景（公告+轮播+排行）
- 前置条件：接口均可用且有数据
- 步骤：
1. 进入首页
2. 校验公告
3. 校验轮播新闻
4. 校验排行榜排序
5. 点击轮播跳转详情并返回首页
- 数据：
- `GET /api/notice`
- `GET /api/news?page=1&limit=5`
- `GET /api/public/leaderboard`
- `GET /api/news/{id}`
- 预期结果：
1. 首页三块数据全部正常展示
2. 新闻详情可打开并回退
3. 首页返回后数据仍可见

### TC-SC-HOME-002
- 编号：`TC-SC-HOME-002`
- 测试点：首页自动刷新场景（排行榜同步时间）
- 前置条件：首页停留 15 秒以上
- 步骤：
1. 进入首页记录首次同步时间
2. 等待自动刷新周期
3. 观察刷新状态和时间变化
- 数据：`GET /api/public/leaderboard` 周期调用
- 预期结果：
1. 刷新图标状态正常
2. 同步时间更新
3. 页面无闪屏、无空白

## 四、错误推测测试

### TC-ER-HOME-001
- 编号：`TC-ER-HOME-001`
- 测试点：公告接口返回空数据
- 前置条件：模拟 `/api/notice` 返回空文本
- 步骤：打开首页
- 数据：`data.text=""` 或无 `text`
- 预期结果：
1. 页面展示“暂无公告”或降级提示
2. 不出现脚本报错

### TC-ER-HOME-002
- 编号：`TC-ER-HOME-002`
- 测试点：新闻列表字段缺失（`thumbnail` 缺失，仅 `cover`）
- 前置条件：新闻数据不含 `thumbnail`
- 步骤：打开首页轮播
- 数据：`items[].cover` 有值，`items[].thumbnail` 为空
- 预期结果：
1. 轮播图仍正常展示封面
2. 点击新闻仍可进入详情

### TC-ER-HOME-003
- 编号：`TC-ER-HOME-003`
- 测试点：排行榜同克重同总资产并列
- 前置条件：构造多条相同 `goldGrams` 和 `totalAsset` 数据
- 步骤：请求排行榜并核对顺序
- 数据：并列记录的 `sequenceNo` 不同
- 预期结果：
1. 并列情况下按 `sequenceNo` 升序排列
2. 前端显示顺序与规则一致

### TC-ER-NEWS-001
- 编号：`TC-ER-NEWS-001`
- 测试点：新闻详情不存在
- 前置条件：使用不存在的新闻 `id`
- 步骤：访问 `/news/{invalidId}`
- 数据：`GET /api/news/{invalidId}`
- 预期结果：
1. 返回 `404`
2. 页面提示“内容不存在或已下线”/加载失败
3. 页面可正常返回，不白屏
