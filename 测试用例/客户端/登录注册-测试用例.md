# 客户端登录注册测试用例

## 覆盖范围
- 页面：`/login`、`/register`
- 文档：`接口文档/客户端/01-登录页-Login.md`、`接口文档/客户端/02-注册页-Register.md`
- 接口：`POST /api/auth/login`、`POST /api/auth/send-otp`、`POST /api/auth/register-with-files`、`POST /api/auth/register`

## 通用前置条件
- 后端可访问，接口前缀为 `/api`
- 测试账号：
- `admin / 正确密码`（有效账号）
- `frozen_user / 正确密码`（冻结账号）
- 已准备测试文件：`idCardFront`、`idCardBack`、`proofFile`（jpg/png，<=5MB）
- 验证码服务可用（开发环境固定验证码 `123456`）

## 一、等价类测试

### TC-EQ-LOGIN-001
- 编号：`TC-EQ-LOGIN-001`
- 测试点：登录有效等价类（合法账号 + 合法密码）
- 前置条件：账号 `admin` 已注册且状态为 `ACTIVE`
- 步骤：
1. 打开登录页
2. 输入合法用户名和正确密码
3. 点击“登录”
- 数据：`username=admin`，`password=正确密码`
- 预期结果：
1. 返回 `200`
2. 响应含 `data.token`、`data.user.uid`、`data.user.roleCodes`
3. 前端写入登录态并跳转 `/home`

### TC-EQ-LOGIN-002
- 编号：`TC-EQ-LOGIN-002`
- 测试点：登录无效等价类（合法账号 + 错误密码）
- 前置条件：账号 `admin` 存在
- 步骤：
1. 登录页输入账号 `admin`
2. 输入错误密码
3. 点击“登录”
- 数据：`username=admin`，`password=wrong123`
- 预期结果：
1. 返回 `401`
2. 提示“账号或密码错误”
3. 不写入 token

### TC-EQ-REGISTER-001
- 编号：`TC-EQ-REGISTER-001`
- 测试点：注册有效等价类（文件注册）
- 前置条件：手机号、用户名均未注册
- 步骤：
1. 调用发送验证码接口获取验证码
2. 在注册页填写完整字段并上传三类文件
3. 点击“完成注册”
- 数据：
- `username=testuser01`
- `password=abc12345`
- `phone=13800000001`
- `otpCode=123456`
- `realName=测试用户`
- `idNumber=110101199001011234`
- `proofType=workCert`
- 预期结果：
1. 返回 `200`
2. 响应含 `data.uid`
3. 提示注册成功并跳转登录页

### TC-EQ-REGISTER-002
- 编号：`TC-EQ-REGISTER-002`
- 测试点：注册无效等价类（验证码错误）
- 前置条件：手机号未注册
- 步骤：
1. 填写合法注册信息
2. 输入错误验证码提交
- 数据：`otpCode=000000`（或 `otp=000000`）
- 预期结果：
1. 返回 `422`
2. 提示“验证码错误或已过期”

## 三、场景法测试

### TC-SC-LOGIN-001
- 编号：`TC-SC-LOGIN-001`
- 测试点：完整登录业务场景
- 前置条件：有效账号存在
- 步骤：
1. 用户打开登录页输入正确账号密码
2. 登录成功后进入首页
3. 刷新页面并访问受保护路由
- 数据：`admin / 正确密码`
- 预期结果：
1. 登录成功
2. 页面刷新后保持登录态
3. 受保护路由可访问

### TC-SC-REGISTER-001
- 编号：`TC-SC-REGISTER-001`
- 测试点：完整注册到登录闭环场景
- 前置条件：手机号和用户名均未注册
- 步骤：
1. 发送验证码
2. 文件注册成功
3. 跳转登录页
4. 使用新账号登录
- 数据：新注册账号一组完整信息
- 预期结果：
1. 注册成功返回 uid
2. 登录成功返回 token
3. 新用户可正常进入首页

## 四、错误推测测试

### TC-ER-REGISTER-001
- 编号：`TC-ER-REGISTER-001`
- 测试点：重复注册同一手机号
- 前置条件：手机号 `13800000001` 已注册
- 步骤：再次发起注册
- 数据：相同手机号，不同用户名
- 预期结果：
1. 返回 `409`
2. 提示“账号或手机号已存在”

### TC-ER-REGISTER-002
- 编号：`TC-ER-REGISTER-002`
- 测试点：文件缺失（少传身份证反面）
- 前置条件：验证码正确
- 步骤：调用 `register-with-files` 少传 `idCardBack`
- 数据：其余字段合法
- 预期结果：
1. 返回 `400`
2. 提示“请上传完整实名资料”

### TC-ER-LOGIN-001
- 编号：`TC-ER-LOGIN-001`
- 测试点：冻结账号尝试登录
- 前置条件：`frozen_user` 状态为冻结
- 步骤：输入正确账号密码登录
- 数据：`username=frozen_user`，`password=正确密码`
- 预期结果：
1. 返回 `423`
2. 提示“账号已冻结，请联系管理员”
3. 前端不应进入首页

### TC-ER-REGISTER-003
- 编号：`TC-ER-REGISTER-003`
- 测试点：`otpCode` 与 `otp` 兼容性（只传 `otpCode`）
- 前置条件：验证码为 `123456`
- 步骤：发起注册请求，仅传 `otpCode` 不传 `otp`
- 数据：`otpCode=123456`
- 预期结果：
1. 返回 `200`
2. 可成功注册，说明前后端兼容字段生效
